# AIDELI

AIDELI(아이델리)는 사람과 AI가 함께 쓰는 개인 작업실이에요. ChatGPT·Claude·Codex를 한 창에서 부르고, 같은 작업 기록 위에서 각자 자기 채팅으로 일하게 해 줘요. Windows 앱이에요.

이 저장소에는 설치 파일만 있어요(소스는 없어요).

## 필요한 것

- Windows 10·11 64비트
- 쓰려는 서비스의 구독 계정: ChatGPT, Claude(Claude Code), Codex(ChatGPT 계정). API 키는 필요 없어요. 로그인만 하면 돼요.

## 설치

1. 오른쪽 **Releases**에서 가장 최근 판의 `AIDELI-Setup-<판>.exe`를 받아요.
2. 받은 파일을 실행해요. 서명하지 않은 앱이라 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.
3. 묻지 않고 바로 깔리고, 바탕화면과 시작 메뉴에 **AIDELI**가 생겨요.

## 처음 켜면

'AIDELI 시작하기'가 떠요.

1. **담당자 로그인**
   - ChatGPT: '체체 원본 열고 로그인'을 눌러 AIDELI 안의 창에서 로그인해요.
   - Claude·Codex: 이 PC에 없으면 **설치**를 눌러요. 공식 설치기가 창에서 돌고, 끝나고 그 창을 닫으면 AIDELI가 다시 확인해요. 그다음 **로그인**을 눌러 브라우저에서 로그인해요.
2. **기준 폴더**: AI가 일하고 메모 자료가 쌓일 폴더 하나를 만들거나 골라요.

웹을 같이 보는 창은 PC에 깔린 브라우저(웨일·Chrome·Edge)를 써요.

## 업데이트

켜 두면 새 판을 알아서 받아 둬요. 작업 목록 맨 아래에 **새 판 x.y.z** 단추가 뜨면 눌러요. 다시 켜지면서 바뀌어요. AI가 일하는 중이면 끝난 뒤에 바뀌어요. 지금 판은 '연결 설정' 머리에 보여요.

## 지우기

Windows 설정 → 앱 → AIDELI → 제거. 작업 기록(`%APPDATA%\AIDELI`)과 기준 폴더는 지우지 않고 남겨 둬요.
